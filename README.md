# Atelier - Statamic Starter Kit

Atelier is a fashion studio starter kit for editorial looks with named directors and a call sheet you can book. Built for Statamic CMS with a modern layout and Control Panel content management.

## Pages of Atelier

- Home Pages: 4 variants
- About Us
- Looks listing, detail, category, and booking
- Schedule
- Events listing and detail
- Experiences listing and detail
- Blog listing and detail
- Podcast listing and episode detail
- Team listing and director detail
- FAQ, testimonials, membership, privacy, terms, contact, 404

## Collections

Pages, blogs, looks, events, experiences, podcasts, teams, testimonials, FAQs, comments.

## Features

- Rich page builder with flexible sets
- Theme-ready design with Tailwind CSS
- Global settings for header, footer, and site-wide copy
- Responsive layout
- Statamic 5 ready

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit). Use **Statamic 5.x**.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/atelier-statamic-theme
```

### Installing via the Statamic CLI Tool

```bash
statamic new my-site webbycrown/atelier-statamic-theme
```
