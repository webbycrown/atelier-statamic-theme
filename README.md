# Atelier - Statamic Starter Kit

Atelier is a fashion studio starter kit for editorial houses, lookbook brands, and booking-led ateliers. It is built for Statamic 5 with a burgundy-and-taupe palette, named directors, a call sheet, and Control Panel content management.

The kit ships four home variants, look listings, booking, events, shop pages, blog and podcast layouts, and membership content so a studio can publish looks and take booking inquiries from one site.

**Live demo:** https://atelier-statamic.webbydemo.in/  
Control Panel: `/cp` — `admin@example.com` / `password`

## Collections

Organize your content with built-in collections (handles in parentheses):

- **Pages**: Site structure and hierarchical content.
- **Looks** (`classes`): Editorial looks and seasonal sets.
- **Events**: Shows, fittings, and launches.
- **Experiences** (`retreats`): Studio days and hosted sessions.
- **Products**: Ready-to-wear and shop items.
- **Blogs**: Editorial notes and studio news.
- **Podcast** and **Podcast episode**: Audio series and individual episodes.
- **Teams**: Directors and stylists.
- **Testimonials**: Client and press quotes.
- **FAQs**: Booking and studio questions.
- **Comments**: Blog and look comments.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Atelier.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/atelier-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Atelier in one command:

```bash
statamic new my-site webbycrown/atelier-statamic-theme
```
